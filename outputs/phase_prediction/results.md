# 意思周期からの最終退出人数の予測

## 本模型での導出

移動則の出典は現行実装 `movement.py` の `Corridor.step` と、依頼文で指定された `movement_note(1).pdf` 第10–11節。手元では実装と既存の移動層READMEで規則を確認した。

周期起点を意思更新番号 μ、周期長を p とする。試行 t が読む意思は更新 n=t×Nd の直後。最初の周期内試行は n≧μ を満たす最小の t≧1 で、位相は (n−μ) mod p。以後、位相は毎試行 Nd ずつ進み、元に戻るまでに p/gcd(p,Nd) 個を訪問する。実際に計算した二値意思ベクトル列でもこの個数と順序を検算した。

有限の吸収通路では、在系の先頭の前方に人がいない。訪問位相に一つでも＋があれば、その位相は有限間隔で反復し、先頭はそのたびに1セル進み、有限回で退出する。旧配置を使うため直後の人が同じ試行で進めない場合でも、以後はその人が先頭になり、同じ議論を適用できる。最初の周期内試行の直前にいる人を出口側からたどると、訪問位相がすべて−の最初の人でこの連鎖が止まる。その人は動かず、右向き一セル・追い越しなしなので後方から抜け出すことはできない。したがって、周期前の退出人数と、その停止者より出口側にいる人数の和が最終退出人数となる。該当者がいなければ全員退出する。流入なし、一定外場、固定乱れ、退出後も全員を意思更新に残す一方向結合を前提とする。

答え合わせは初期条件から独立に `SocialRing.update` と `Corridor.step` を回し、全員退出か、移動直後の全IDの位置・在系状態・全員の意思の再出現で確定した。再出現の間に退出は起こり得ない。上限は意思周期の探索が4,096意思更新、答え合わせが4,096移動試行。確定できなければ「未確定」とし、200試行値は別に残す。

## 優先15条件

全15件で予測と独立計算が一致した。先頭人数を数える配置は、最初の周期内移動の直前を使った。全15件でその時点の退出済み人数は0。全条件の1行ずつの表は [priority.csv](priority.csv) を参照。

| seed / h | 意思周期 | Nd と訪問位相 | 出口に最も近い恒久停止者 | 予測・独立計算・t=200 |
|---|---|---|---|---|
| 102 / 0 | μ=3、p=2 | 1・3 は 0→1 | P08、セル22 | 各16人 |
| 102 / 0 | μ=3、p=2 | 2・4・8 は 1 | P24、セル47 | 各0人 |
| 102 / 0.35 | μ=2、p=4 | 1 は 0→1→2→3、2 は 0→2、3 は 1→0→3→2、4・8 は 2 | 全 Nd で P08、セル22 | 各16人 |
| 101 / 0.70 | μ=3、p=1 | 全 Nd で 0 | 全 Nd で P01、セル7 | 各23人 |

seed 102・h=0 では P24 が位相0で＋、位相1で−。両位相を読む Nd=1・3 では P24 を含め P08 より出口側の16人が退出した。h=0.35 では P08 がどの位相でも−で、Nd を変えても同じ16人が退出した。

seed 101・h=0.70 の最初の退出者は全 Nd で P24。初期セル48から、Nd=1 では t=1 に意思−で停止、t=2 から進み、t=17 にセル64、t=18 にセル65へ退出した。Nd=2・3・4・8 は t=1 にセル49へ進み、t=16 にセル64、t=17 にセル65へ退出した。最終人数は全条件で23人。判定は最終人数を説明し、この1試行の時間差は周期前も含めた個人の移動履歴で分かる。

## 既存60条件と新規160条件

| 対象 | 一致 / 全条件 | 不一致 | 未確定 |
|---|---:|---:|---:|
| 既存 seed 101–103 | 60 / 60 | 0 | 0 |
| 新規 seed 104–111 | 160 / 160 | 0 | 0 |

既存60条件では t=0–200 の退出曲線を保存済みの曲線と照合した。全220条件で t=200 の退出人数と確定した最終人数は一致した。回帰テストは、周期前の退出と複数停止者、正位相が4試行に一度の先頭者、停止者なしでの同期排他、追跡上限での未確定を検査する。

| 外場 h | Nd で最終退出人数が変わった新規標本 |
|---:|---:|
| 0 | 0 / 8 |
| 0.35 | 1 / 8 |
| 0.70 | 0 / 8 |
| 1.05 | 0 / 8 |

変化があったのは seed 104・h=0.35。周期は n=9 からの2更新。Nd=1・3 は両位相を読み、P23 が停止者となり P24 が t=33 に退出して最終1人。Nd=2・4・8 は位相1だけを読み、P24 が停止者となって最終0人だった。各seed内の5条件で固定乱れ・初期値を共有した対応比較である。

seed 104 の最初の20条件は約0.095秒、チェックポイントは53,671バイト。全条件では判定とID別の位相要約だけを保存し、個人全軌道は新規保存していない。各条件の完了後にチェックポイントを更新する。
