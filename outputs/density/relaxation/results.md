# 意思緩和の小検算

再現は `python3 -B density_relaxation.py`。隣接研究リポジトリの `local_gaussian_closure/src/model.py` と `kernel.py` を読み込み、G0 の空間更新と一様写像の導関数を再利用した。理論ノート §2.3 (2.17–2.23)、§7 (7.14–7.20)、§17.2 に従う。M=24、R=4、σ=0.2、μ=0.45、φ̄=h=0、σeff=0.45。G0(0)=0、G0′(0)=0.79788456。規格化された非負核のフーリエ成分の絶対値は1以下なので全モードで安定である。

初期摂動 ε cos(qα) の核畳み込みは対称性により ε cos(qα) × Σ[r^−1.2 cos(qr)] / Σ[r^−1.2]（両和は r=1,…,4）。これを一様写像の固定点まわりで一次展開すると、符号付き振幅比は G0′(0) とこの有限和比の積になる。測定は更新後の偏差を同じ余弦に射影して初期射影で割った。

|q|理論比|絶対誤差 ε=0.01|ε=0.003|ε=0.001|
|---|---:|---:|---:|---:|
|0|0.79788456|1.33×10⁻⁵|1.20×10⁻⁶|1.33×10⁻⁷|
|2π/24|0.68594040|6.34×10⁻⁶|5.70×10⁻⁷|6.34×10⁻⁸|

二値模型では h=0.35、同じ固定乱れ・初期意思から到達した各周期位相で、一更新だけ ε cos(2πα/24) の外場を加え、無摂動と比較した。seed 101・103 は固定点、102 は周期4の全位相を測った。振幅0.01では反転0/3標本、0.03と0.05では各1/3標本。応答したのは seed 101 の P22 一人で、符号付き意思差の射影は0.117851、他標本は0。周期4内部の自然な反転は、同じ位相の無摂動更新との差を取ることで除いた。測定対象は一更新の応答で、臨界指数は推定していない。
