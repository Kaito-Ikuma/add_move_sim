# P1 初期密度と初期間隔

再現は `python3 -B density_study.py density`、`python3 -B density_study.py render`、`python3 -B -m unittest -v`。固定ID順に24人、人口区間の右端96、出口113、1セル1 m・1試行1秒。後方からの番号を i=0,…,23、人口区間長を B として初期セルを 96−floor((23−i)B/24) とした。B=96,48では中心間隔4,2、B=32では間隔1,1,2の繰り返し（位相は出口側に整列）となる。全IDの初期セルは people.csv にある。密度0.50も通路長112・規則配置の新対照である。

## 200試行の到達人数

各欄は Nd=1,2,3,4,8 の順。各欄の全ID・人数は3密度で一致した。135条件の200試行人数と周期判定による最終予測も一致した。

|seed|h=0|h=0.35|h=0.70|密度間で途中の退出曲線が異なる条件|
|---|---|---|---|---|
|101|全て0|全て0|全て23|5 / 15|
|102|16,0,16,0,0|全て16|全て24|12 / 15|
|103|全て0|全て0|全て9|5 / 15|

全45組のうち途中で差があるのは22組、全時刻で同じなのは23組。同じ n の全24人の意思を、退出後も含む200試行分、独立に生成した社会層単体の軌道と照合した。各人の試行数は移動＋意思停止＋排他停止と一致し、退出者の移動数は出口113までの初期距離と一致した。

## 同じ人の時間の内訳

seed 102、h=0.70、Nd=1。P24 は全密度でセル96から17試行で退出。P01 の到達を下表に示す。

|初期密度|初期セル|必要移動|意思停止|排他停止|到達時刻|純粋移動の到達時刻|全員の排他停止人回|
|---:|---:|---:|---:|---:|---:|---:|---:|
|0.25|4|109|0|0|109|109|0|
|0.50|50|63|0|1|64|63|15|
|0.75|66|47|0|16|63|63|191|

高密度のP01は低密度より62 m出口に近く、排他待ちは16秒長いので、46秒早く到達した。t=63 の累積到達は12人対24人。同じ配置の純粋移動での全員分の排他停止は密度順に0、0、192人回。密度0.75の純粋移動ではすでにP01に16試行の排他待ちがある。

seed 101、h=0.70、Nd=1 では全密度で23人退出し、全員の意思停止は各202人回、排他停止は0、20、197人回。seed 103、h=0.70、Nd=1 では全密度で9人退出し、全員の意思停止は各401人回、排他停止は2,325、2,507、2,595人回。未退出者は200試行までを集計し、退出時刻欄は空欄とした。条件間で共通の退出IDについては paired_exits.csv に高密度−低密度の到達時刻・三分類差を保存した。

## 発表例と記録

全45組で密度対の累積到達人数の最大絶対差を調べ、最大の対を選んだ。同率は seed、h、Nd、小さい側の密度、大きい側の人口区間長の昇順。選出条件は上表の密度0.25と0.75。compare.html と replay_curves.svg は同じ2本の保存ログから再生成する。HTMLで t=63 に合わせると最大差が見える。

conditions.csv は未退出者を含む全員の200試行集計、people.csv は3,240人条件の個人分解、pure_people.csv・pure_trials.csv は対応する純粋移動対照。arrivals.svg・stops.svg は135条件をseed、h、Ndごとに表示する。最初の3密度の処理時間と要約をコンパクトJSONにした容量は benchmark.json に記録した。
